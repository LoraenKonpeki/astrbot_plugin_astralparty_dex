# 指令帮助

以下内容与插件内帮助一致，使用机器人的 `~` 唤醒前缀。查询默认将全部结果合并为一张图片，无需翻页；图片失败时自动回退文字。

## 总帮助

```text
星趴档案助手 · 指令帮助

账号（请私聊）
~星趴 登录 手机号 —— 发送短信验证码
~星趴 验证 验证码 —— 登录并绑定当前聊天用户
~星趴 状态 —— 查看绑定与连接状态
~星趴 刷新 —— 重新获取自己的资料与战绩
~星趴 解绑 —— 删除保存的凭据并关闭会话

资料与战绩
~星趴 我的 —— 个人资料与统计
~星趴 战绩 [UID或我的] —— 一张图展示最近最多 10 局
~星趴 对局 回放号或序号 —— 对局玩家与统计
~星趴 复盘 回放号或序号 玩家UID —— 一张图展示全部轮次与筹码
~星趴 角色 —— 全部已拥有角色使用排行
~星趴 皮肤 [角色名或角色ID] —— 拥有的皮肤与契约状态

详细帮助：~星趴 帮助 指令名
例如：~星趴 帮助 登录、~星趴 帮助 复盘
也可：~星趴 登录 帮助（所有指令均支持）

按回放号查询无需登录；UID 查询需要自己的登录态。
登录/刷新可能使正在运行的游戏客户端下线，请先退出游戏。
群聊可查询，登录与验证码只在私聊执行。
```

## 帮助

```text
用法：~星趴 帮助 [指令名]
不加指令名显示总帮助；添加指令名显示用途、参数、示例与限制。
例如：~星趴 帮助 战绩，也可使用 ~星趴 战绩 帮助。
```

## 登录

```text
用途：发送短信验证码，开始账号绑定。
用法：~星趴 登录 手机号
示例：~星趴 登录 你的11位手机号
仅私聊执行；群聊会拒绝并提示私聊，不会发短信。
发送成功后 5 分钟内使用 ~星趴 验证 验证码。每个用户、手机号发送冷却 60 秒。
当前版本支持中国大陆手机号短信登录。插件不提供 Steam/B站/TapTap 本机登录票据读取。
登录查询可能挤掉游戏客户端，请先退出游戏。
```

## 验证

```text
用途：提交短信验证码，完成登录和账号绑定。
用法：~星趴 验证 验证码
仅私聊执行，先用 ~星趴 登录 手机号；最多尝试 5 次。
验证码仅临时使用；长期登录凭据加密保存在机器人服务器。
账号已在游戏中在线时，插件不会自动重试接管；退出游戏后可私聊 ~星趴 刷新。
```

## 状态

```text
用途：查看当前聊天用户绑定的游戏账号、UID 与会话连接状态。
用法：~星趴 状态
不会发起游戏登录；“凭据已保存”不代表凭据仍然有效。
同平台、同机器人实例的私聊绑定可在群聊查询；不同平台或机器人实例分别绑定。
```

## 刷新

```text
用途：重新登录游戏协议，获取自己的最新资料和近期战绩。
用法：~星趴 刷新
仅私聊执行，冷却 30 秒。可能使游戏客户端下线，请先退出游戏。
普通查询会复用资料快照并显示获取时间；玩完游戏后主动刷新。
凭据过期时需要重新使用 ~星趴 登录 手机号。
```

## 解绑

```text
用途：删除当前聊天用户保存的登录凭据、待验证登录与列表序号，关闭游戏连接。
用法：~星趴 解绑
仅私聊执行，不删除游戏账号；以后需要重新验证码登录。
回放文件属于公共缓存，不随个人解绑删除，会按缓存期限清理。
```

## 我的

```text
用途：查看昵称、UID、等级、场次、胜场、胜率、角色数、皮肤数与获赞。
用法：~星趴 我的
需先私聊绑定，可在群聊查询自己的公开统计。
资料是最近成功登录时的快照，结果标注获取时间；需要更新时私聊 ~星趴 刷新。
群内回复会公开这些游戏资料。
```

## 战绩

```text
用途：一张图查看最近最多 10 局战绩。
用法：~星趴 战绩 [UID或“我的”]
示例：~星趴 战绩、~星趴 战绩 我的、~星趴 战绩 1234567
不填 UID 查询自己；指定 UID 也需要调用者先绑定账号。
结果带名次、角色、时间、模式和回放号，完整展示服务返回的近期记录。
随后可 ~星趴 对局 1；序号对应当前用户在当前群/私聊最近一次战绩列表，10 分钟后过期。
返回范围受游戏服务限制，不保证有 10 局。
```

## 对局

```text
用途：查看一局玩家、角色、等级、击杀、伤害、承伤与星币统计。
用法：~星趴 对局 回放号或战绩序号
示例：~星趴 对局 1234567890123456、~星趴 对局 1
直接输入回放号无需登录；序号需先在当前会话查看战绩。
名次在当前战绩列表包含对应记录时显示；回放缺少结算名次时显示“未知”。
回放过期、过大或协议变化时会提示原因。
```

## 复盘

```text
用途：一张图查看指定玩家全部轮次的击杀、伤害、承伤、星币、步数、阵亡及筹码获取。
用法：~星趴 复盘 回放号或序号 玩家UID
示例：~星趴 复盘 1 1234567
完整展示所有轮次，筹码列出来源、候选项、选中项与刷新次数。
直接按回放号查询无需登录，玩家 UID 必须存在于该对局；未知 UID 可先使用 ~星趴 对局 回放号。
轮次统计与筹码来源根据快照和协议记录推导，部分回放可能缺数据；未知项会如实展示。
```

## 角色

```text
用途：一张图查看全部已拥有角色的使用排行、场次、胜场、胜率、PVE 等级与潜能状态。
用法：~星趴 角色
需绑定账号，按使用场次排序。
潜能开放状态参考随插件附带的静态表，可能落后于游戏更新。资料刷新方式见 ~星趴 帮助 刷新。
```

## 皮肤

```text
用途：一张图查看自己全部已拥有角色的皮肤和契约状态，也可筛选角色。
用法：~星趴 皮肤 [角色名或角色ID]
示例：~星趴 皮肤、~星趴 皮肤 101、~星趴 皮肤 帕露南
省略参数显示全部已拥有角色；数字按角色 ID 查询，角色名支持包含匹配。
✓ 表示拥有，○ 表示未拥有。未知皮肤显示编号，名称表可能落后于游戏更新。
只查询当前绑定账号，不允许读取其他用户的背包。
```
